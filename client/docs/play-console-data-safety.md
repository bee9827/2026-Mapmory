# Mapmory Play Console 데이터 보안 응답표

기준: `main` 출시 AAB에서 실제로 실행되는 기능.

## 현재 구현 확인

- 여행 기록과 지역 검색 정보는 앱 메모리에서만 처리됩니다.
- Ktor 원격 저장소 코드는 있으나 현재 앱 실행 경로에는 연결되지 않았습니다.
- `X-Member-Id`는 현재 앱에서 서버로 전송되지 않습니다.
- 카메라·사진 권한 관련 코드는 있으나 현재 화면에서 권한을 요청하거나 사진에 접근하지 않습니다.
- Firebase, Mapbox, 광고·분석·추적 SDK를 사용하지 않습니다.
- 위치 권한과 GPS 수집 기능이 없습니다.

## Play Console 응답

| 질문 | 응답 |
| --- | --- |
| 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? | 아니오 |
| 광고를 포함하나요? | 아니오 |
| 로그인 또는 리뷰어 계정이 필요한가요? | 아니오 |
| 데이터 유형 | 선택 항목 없음 |

Google Play은 기기 안에서만 처리되고 기기 밖으로 전송되지 않는 사용자 데이터를 데이터 보안 양식의 수집 대상으로 보지 않습니다. 사용자 데이터를 수집하지 않는 앱도 양식을 제출하고 개인정보처리방침 URL을 제공해야 합니다.

## 배포 직전 재확인

- [ ] 실제 제출 AAB가 이 문서의 기준 커밋에서 빌드되었는가
- [ ] 원격 저장소가 앱 실행 경로에 연결되지 않았는가
- [ ] 카메라·사진·위치 권한을 실제로 요청하지 않는가
- [ ] Firebase, Mapbox, 광고·분석·추적 SDK가 추가되지 않았는가
- [ ] 네트워크 프록시로 사용자 데이터가 외부에 전송되지 않는지 확인했는가
- [ ] 변경이 있다면 데이터 보안 응답과 개인정보처리방침을 함께 갱신했는가
