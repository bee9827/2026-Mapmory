# 함께 채우는 기억의 지구본 — 실험 기획서

- 상태: 아이디어 백로그 · 미구현
- 결정일: 2026-08-27
- 적용 위치: 메인 랜딩이 아닌 별도 실험 페이지 또는 캠페인
- 구현 전제: 실제 제품 로드맵과 개인정보·운영 정책 검토 후 별도 승인

## 한 줄 정의

방문자가 자신에게 기억이 있는 나라를 선택하면 참여 수가 집계되고, 모든 방문자가 함께 채워진 세계지도를 볼 수 있는 참여형 캠페인이다.

## 왜 메인 랜딩과 분리하는가

Mapmory의 핵심은 `나의 사진과 장소로 개인 기억 지도를 만드는 것`이다. 공동 지도를 메인 랜딩에 넣으면 커뮤니티·여행 통계 서비스로 오해될 수 있고, 실제 앱에 없는 기능을 기대하게 만들 수 있다.

따라서 이 아이디어는 다음 원칙을 지킨다.

- 메인 랜딩의 제품 설명과 전환 흐름에는 포함하지 않는다.
- 별도 URL과 별도 캠페인 이름으로 운영한다.
- 공동 지도는 Mapmory의 정식 기능이 아니라 실험임을 명시한다.
- 실험 결과가 좋아도 앱 기능으로 자동 편입하지 않는다. 제품 로드맵 결정을 별도로 거친다.

## 검증하려는 가설

> 사람들이 자신의 여행 기억을 한 번의 클릭으로 공동 지도에 보태는 경험을 재미있게 느끼면, Mapmory의 개인 기억 지도에도 더 높은 관심을 보일 것이다.

검증할 질문은 세 가지다.

1. 방문자가 설명 없이도 지구본을 돌리고 국가를 선택하는가?
2. 선택한 국가에 자신의 기억을 보태는가?
3. 참여 이후 Mapmory의 개인 기억 지도나 출시 알림으로 이동하는가?

## 권장 사용자 흐름

1. 방문자가 별도 캠페인 페이지에 들어온다.
2. `Mapmory 방문자들이 함께 채우는 기억의 지구본`이라는 설명을 본다.
3. 3D 지구본을 직접 돌린다.
4. 국가를 선택한다.
5. 패널에서 `나도 이곳에 기억이 있어요`를 누른다.
6. 해당 국가의 참여 수가 1 증가하고 색 농도가 바뀐다.
7. 패널에 정확한 참여 수가 표시된다.
8. 사용자는 선택을 취소할 수 있다.
9. 참여 후 `내 기억 지도 알아보기`를 통해 메인 랜딩 또는 앱 소개로 이동한다.

## 첫 MVP 범위

포함한다.

- 지구본 회전
- 국가 선택
- 국가별 한 번 참여
- 참여 취소
- 국가별 집계 수 표시
- 참여 수에 따른 색 농도 변화
- 모든 방문자가 같은 집계 결과 조회
- 모바일·데스크톱 대응
- 기본적인 중복 방지와 요청 속도 제한

포함하지 않는다.

- 사진 업로드
- 여행 기록 작성
- 댓글·피드·팔로우
- 사용자 프로필
- 국가별 순위 경쟁
- 실시간 채팅
- 정식 Mapmory 기록과의 자동 연동
- 메인 랜딩 또는 앱 DB의 기존 기억 데이터 변경

## 지도 표현 규칙

참여 수는 국가의 실제 3D 높이보다 표면 색 농도로 표현한다. 국가 면적에 따른 착시와 지구본의 시각적 복잡도를 줄이기 위함이다.

초기 고정 구간 예시:

| 참여 수 | 표현 |
| --- | --- |
| 0 | 기존 어두운 회색 |
| 1–4 | 흐린 민트 |
| 5–14 | 중간 민트 |
| 15–39 | 선명한 민트 |
| 40 이상 | 가장 밝은 민트 |
| 현재 선택 | 금색 테두리 또는 금색 강조 |

초기 데이터가 충분히 쌓인 뒤에는 실제 분포를 보고 구간을 다시 정한다. 색만으로 정보를 전달하지 않고 선택 패널에 정확한 숫자를 함께 표시한다.

## 문구 초안

페이지 제목:

> 우리에게 기억이 있는 곳을 함께 채워요.

설명:

> 지구본을 돌려 마음에 남은 나라를 골라보세요. 한 번의 선택이 모두의 기억 지도를 채웁니다.

국가 선택 패널:

> 중국<br>
> 18명이 이곳에 기억이 있어요.<br>
> `나도 이곳에 기억이 있어요`

참여 후:

> 당신의 기억이 지도에 더해졌어요.<br>
> `선택 취소` · `내 기억 지도 알아보기`

## 데이터 설계 초안

정확한 테이블명은 실제 백엔드 규칙에 맞춰 조정한다.

### 국가별 집계

`community_country_memory_counts`

| 필드 | 설명 |
| --- | --- |
| `country_code` | ISO 국가 코드, 고유 키 |
| `vote_count` | 현재 유효 참여 수 |
| `updated_at` | 마지막 변경 시각 |

### 중복 참여 방지

`community_country_memory_votes`

| 필드 | 설명 |
| --- | --- |
| `id` | 참여 식별자 |
| `country_code` | 선택한 국가 코드 |
| `participant_hash` | 원문을 저장하지 않는 익명 참여 식별값 |
| `created_at` | 참여 시각 |

`country_code + participant_hash`에 고유 제약을 둬 동일 참여자가 같은 국가에 중복 참여하지 못하게 한다.

초기에는 서버가 발급한 익명 식별 쿠키를 사용할 수 있다. 이 경우 쿠키 고지, 보유 기간, 해시 처리와 삭제 정책을 개인정보 검토에 포함한다. 로그인 기반 참여는 MVP 이후에만 검토한다.

## API 초안

- `GET /api/experiments/community-globe/countries`
  - 국가별 현재 참여 수를 반환한다.
- `PUT /api/experiments/community-globe/countries/{countryCode}/vote`
  - 현재 참여자의 국가 선택을 생성한다.
- `DELETE /api/experiments/community-globe/countries/{countryCode}/vote`
  - 현재 참여자의 선택을 취소한다.

서버 요구사항:

- ISO 국가 코드 검증
- DB 트랜잭션 또는 원자적 증감
- 중복 요청의 멱등성
- IP·식별자 기준 속도 제한
- 집계 수가 음수가 되지 않는 제약
- 캐시 사용 시 참여 직후 자신의 최신 값 보장

MVP에서는 WebSocket이 필요하지 않다. 페이지 진입, 국가 선택, 참여 직후에 최신 집계를 다시 불러오면 충분하다. 정말 즉시 갱신되는 공동 경험이 필요하다는 근거가 생기면 SSE 또는 WebSocket을 다음 단계에서 검토한다.

## 개인정보와 운영 원칙

- 이메일, 사진, 위치 이력, 여행 날짜를 수집하지 않는다.
- 익명 식별값은 원문 복원이 어렵도록 서버에서 해시 처리한다.
- 개인정보처리방침과 쿠키 안내에 실험 목적과 보유 기간을 명시한다.
- 참여 취소 방법을 제공한다.
- 비정상적으로 많은 요청은 제한한다.
- 국가·지역을 평가하거나 인기 순위를 만드는 표현은 피한다.
- 분쟁 지역과 국가 표기 방식은 기존 Mapmory 지도 데이터 정책을 따른다.

## 측정 계획

### 핵심 지표

- 지구본 참여율 = 한 국가 이상 투표한 방문자 / 캠페인 고유 방문자

### 보조 지표

- 지구본 조작률 = 회전 또는 국가 선택 방문자 / 캠페인 고유 방문자
- 국가 선택 후 참여 전환율 = 투표 방문자 / 국가 선택 방문자
- 참여자당 선택 국가 수
- 참여 후 제품 탐색률 = `내 기억 지도 알아보기` 클릭 방문자 / 투표 방문자
- 캠페인 이탈률과 모바일 오류율

### 제안 이벤트

- `community_globe_view`
- `community_globe_interact`
- `community_country_select`
- `community_vote_submit`
- `community_vote_remove`
- `community_product_cta_click`

이벤트명은 구현 전에 기존 분석 택소노미와 중복 여부를 검토하고 확정한다.

## 성공·보류·실패 기준 초안

표본이 너무 작으면 비율이 크게 흔들리므로 최소 300개의 고유 캠페인 세션을 모은 뒤 판단한다. 기간은 최소 2주를 권장한다.

| 판정 | 기준 |
| --- | --- |
| 성공 | 지구본 조작률 40% 이상, 참여율 25% 이상, 참여 후 제품 탐색률 10% 이상 |
| 보류 | 참여율 10–24% 또는 표본 300개 미만. 문구·진입 경로를 한 번만 수정해 재검증 |
| 실패 | 표본 충족 후 참여율 10% 미만이거나 반복적인 오류·남용으로 운영비가 가치보다 큼 |

수치는 업계 평균과 비교하기 위한 목표가 아니라, 이 아이디어를 계속 투자할지 판단하기 위한 내부 기준이다. 캠페인 유입 채널이 달라지면 채널별로 따로 본다.

## Lean 실행 순서

1. 코드 없이 5명에게 정적 목업을 보여주고 의미를 설명하게 한다.
2. `다녀온 나라`와 `기억이 있는 나라` 중 어떤 표현이 Mapmory답게 이해되는지 확인한다.
3. 클릭 가능한 프론트엔드 프로토타입으로 지구본 조작과 참여 흐름만 검증한다.
4. 반응이 확인되면 별도 실험 테이블과 API를 만든다.
5. 내부·제한 공개 환경에서 중복 방지와 집계 정확성을 검증한다.
6. 별도 캠페인 URL로 2주 또는 300세션 이상 운영한다.
7. 성공 기준을 충족하면 확장 여부를 결정한다.

## 결정 기록

- 메인 Mapmory 랜딩에는 공동 참여 DB 기능을 넣지 않는다.
- 현재 랜딩의 3D 지구본은 실제 팀 기억을 체험하는 제품 증명 역할을 유지한다.
- 공동 참여 지구본은 별도 실험 페이지나 캠페인으로만 검토한다.
- 첫 MVP는 익명 국가별 집계에 집중하고 사진·기록·소셜 기능은 제외한다.
- 현재 문서는 구현 승인이 아니라, 나중에 다시 시작할 수 있도록 남기는 실행 가능한 아이디어 기록이다.
