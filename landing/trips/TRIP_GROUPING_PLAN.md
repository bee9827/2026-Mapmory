# 여행 후보 자동 분류 기준

2026-09-23 · 기본 위치 분류 + 맨 아래 선택형 촬영 패턴 실험 · GA4 연결 준비

## 목적과 현재 흐름

사진 선택 → Recap 방식으로 메타데이터 읽기 → 분류된 앨범 → 같은 화면 아래 설문.
편집·확정·홈 선택·사전 위치/날짜 검토 단계를 두지 않는다. 위치·날짜 폴더와
원본 ZIP은 보조 버튼으로만 연다. 앨범을 설명과 안내보다 먼저 보여준다.

자동 분류는 여행의 정답이 아니라 제안이다. 모든 사진은 여행 후보 또는 단일
‘분류 보류’ 앨범에 한 번씩 남으며, 원본을 삭제하거나 추정 GPS를 쓰지 않는다.

## 세 가지 경우

| 사진 상태 | 분류 방법 | 표시 |
|---|---|---|
| 위치·날짜 있음 | 실제 좌표와 연속된 날짜로 작은 방문 묶음 | 관측 · 위치와 날짜 |
| 일부 위치만 있음 | GPS 방문을 먼저 만든 뒤 명확한 촬영 시간 근거로 연결 | 관측 + 추정 · 촬영 시간으로 연결 |
| 사용할 GPS·날짜 기준 없음 | 촬영량 추정 없이 모든 사진을 보류 | 분류 보류 |

시간 연결이 애매한 사진, 위치 기준이 없는 사진, 날짜 없는 사진은
날짜별로 잘게 나누지 않고 **분류 보류 앨범 하나**에 모은다. 이 앨범이 하나의 여행이라는 뜻은 아니다.
GPS만 있고 날짜가 없는 사진도 여행 기간 판단에 사용하지 않는다.

## 현재 실험값 — 검증된 기준 아님

### 위치·날짜

- 촬영 시간순으로 처리한다. 첫 GPS 기준점에서 30km 이내, 직전 GPS 사진과
  36시간 이내, 같은 날 또는 다음 날이어야 같은 방문이다.
- 같은 장소라도 날짜가 끊기면 별도 방문이다. A→B→A도 각각 나눈다.
- 첫 좌표를 기준으로 하여 점진적인 이동이 끝없이 한 지역으로 이어지는 것을 막는다.
- 위치 없는 사진은 한 방문의 앞뒤 GPS 사진 사이이며, 가까운 GPS 사진과 6시간 이내이고,
  연결 가능한 방문이 정확히 하나일 때만 포함한다. 경계 밖으로 외삽하지 않는다.
- 지역 이름은 표시용이다. 실제 분류는 좌표로 하며 일상·출장·장기간 같은 지역에서 찍은
  사진도 후보일 수 있다. 생활 지역을 입력하지 않는 것이 여행 여부를 안다는 뜻은 아니다.

### 촬영량 — 기본은 보류, 선택형 실험

- 기본 화면에서는 촬영량으로 여행을 추정하지 않는다. 사용자가 맨 아래 실험 버튼을 누른 경우만 실행한다.
- 일상 사진이 있으면 비교에 도움이 되며 여행 사진만 있으면 추정이 어려울 수 있다고 짧게 안내한다. 사진 재선택이나 추가 확인을 강제하지 않는다.
- 비교값은 선택한 전체 사진 중 촬영일이 있는 사진의 일별 장수 중앙값이다. GPS 없는 보류 사진만으로 비교값을 만들면 표본이 달라지므로 전체 선택을 쓴다.
- 후보 대상은 아직 보류된 GPS 없는 사진뿐이다. 이미 위치·시간으로 연결된 사진은 중복 분류하지 않는다.
- 초기 실험값: 기간 14일 이상, 촬영일 7일 이상, 급증 기준 미만 촬영일 5일 이상. 기준은 중앙값 3배 이상이면서 하루 10장 이상이다. 보류 대상 사진의 일별 장수가 기준을 넘은 연속 날짜만 묶는다.
- 조건을 만족해도 일상이 실제로 포함됐다고 판정하지 않는다. 조건 부족·급증 없음·촬영일 없음은 보류 유지다.
- 기본 앨범과 ZIP은 바꾸지 않고, 보류 앨범의 일부를 다시 본 별도 실험 미리보기로 표시한다. 사진 수를 기본 앨범과 더하면 중복이므로 합산하지 않는다.
- 결과와 함께 평균·중앙값·최대값·급증 기준·급증 날짜 수를 보여준다. 첫~마지막 선택 촬영일 사이 공백도 세지만, 실제 미촬영일로 간주하거나 평균에 0으로 넣지 않는다.

기존 Recap 리더의 촬영 시간을 그대로 사용한다. 해외 시간대 이동을 보정하지 않아 경계가
달라질 수 있다. 현재 위치 권한이나 이미지 분석을 추가하지 않는다.

## 범위와 개인정보

사진 선택당 최대 1,000장, 50MB 초과 파일은 개별 제외하고 결과에 수를 표시한다.
원본·촬영일·GPS는 브라우저 메모리에만 있고 새로고침하면 결과가 사라진다.
여행별 ZIP이나 영구 저장은 이번 범위가 아니다. 기존 위치·날짜 ZIP 구조는 유지한다.
설문은 선택 사항이며 사용자가 제출한 응답만 Google Forms로 전달된다.

## 다음 사용자 검증

여행 기록 사용자 3명의 많은 사진은 탐색 근거이지 분류 정확도 검증 결과가 아니다.
참여자가 직접 정한 여행 기간과 비교해 잘못 합침·잘못 나눔·놓침을 위치 전체/일부/없음으로 구분한다.
위치 없는 참여자는 누락 진단에 포함하되 위치 기반 분류 효과 평가와 구분한다.
선택형 실험은 탐색적 가설 검증이며 A/B 테스트가 아니다. 실행률은 사용 의도, 근거 부족 비율은 현재 입력의 제약을 보여줄 뿐이다. 정확도·만족도는 설문으로 별도 확인한다.

이번 UI 변경은 실험 준비 과정이며 무작위 A/B 비교나 성과 개선의 증거가 아니다.
앨범 펼침·설문 링크 클릭을 만족도로 해석하지 않는다. 만족도와 분류 정확도는 설문으로 확인한다.
Android 비카카오톡 환경은 기존 제품 효과 평가에서 제외하고 진단에는 별도로 표시한다.

GA 운영 수집은 계속 OFF다. 파일명·날짜·GPS·묶음 ID를 이벤트에 넣지 않는다.
